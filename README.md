# SUCA Labs — Core Components

هذا مستودع عام محدود يضم مكونات C وأدوات تحقق مستقلة من مشروع SUCA OS Mobile، مثل Device Profile وHAL وUpdate State وRecovery State. أُخرجت منه ملفات boot وDTB وتعريفات الأجهزة الخاصة وأي أسرار أو بيانات تشغيلية.

## المحتوى

المجلد `shared/` يحتوي على عقود ومكونات C صغيرة قابلة لإعادة الاستخدام. المجلد `tests/` يحتوي على اختبارات منطقية. المجلد `tools/` يحتوي على مدققات ملفات التعريف وmetadata. المجلد `docs/` يحتوي على وثائق مختصرة للتصميم.

## الحدود

هذا المستودع لا يحتوي على kernel أو boot image أو DTB أو firmware أو مفاتيح توقيع، ولا يثبت دعم أي هاتف حقيقي. نجاح الاختبارات يثبت منطق المكونات فقط.

## الترخيص

لم يُحسم الترخيص العام بعد. يجب اختيار الترخيص قبل النشر النهائي.
